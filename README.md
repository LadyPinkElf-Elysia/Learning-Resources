# 📚 学习资料库

> 一个个人学习资料管理工具，支持按学科分类浏览，文件结构清晰，便于扩展和维护。

## 📖 简介

这是一个基于原生 JavaScript 构建的轻量级学习资料导航页。所有资料按学科分类整理，以树形结构展示，点击文件夹即可展开/收起，点击文件可直接打开查看。

项目已拆分为 `index.html`、`style.css`、`main.js` 三部分，结构清晰，方便二次开发。

## 🧩 功能

- ✅ 树形目录浏览（点击文件夹展开/收起）
- ✅ 空目录友好提示（“📭 目前暂无资料”）
- ✅ 文件点击跳转（在新窗口打开）
- ✅ 数据驱动渲染（修改 `app.data` 即可更新界面）
- ⏳ 添加文件/文件夹（功能已预留，暂未开放）

## 🚀 使用方式

1. 访问 GitHub Pages 地址（或本地打开 `index.html`）
2. 点击 `📁` 文件夹展开/收起子目录
3. 点击 `📄` 文件链接，在新窗口查看

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript
- ES6 Class 封装（`LearningApp` 类）
- 递归渲染引擎

## 🔧 扩展开发

### 数据结构说明

数据存储在 `app.data` 中，规则如下：

- 对象 `{}` → 文件夹
- 数组 `[]` → 文件列表
- `_files` → 当前目录下的文件（当文件夹同时含有子文件夹和文件时使用）

### 添加新资料

目前添加功能暂未开放，如需手动添加，可直接修改 `main.js` 中的 `data` 对象，然后调用 `app.render()` 刷新界面。
