# 📚 学习资料库

> 一个模块化的学习资料管理工具，支持按学科分类浏览，树形结构展示，便于扩展和维护。

## 📖 简介

这是一个基于原生 JavaScript 构建的轻量级学习资料导航页。所有资料按学科分类整理，以树形结构展示，点击文件夹即可展开/收起，点击文件可直接打开查看。

项目采用**模块化架构**，将数据管理、渲染引擎、文件存储、统计功能拆分为独立模块，职责清晰，便于二次开发和功能扩展。

## 🧩 功能

- ✅ 树形目录浏览（点击文件夹展开/收起）
- ✅ 空目录友好提示（“📭 目前暂无资料”）
- ✅ 数据驱动渲染（修改数据即可更新界面）
- ✅ 模块化架构（DataManager、RenderEngine、FileStorage 独立）
- ⏳ 添加文件/文件夹（功能已预留，暂未开放）

## 🚀 使用方式

1. 使用 Live Server 或任何 HTTP 服务器打开项目（ES Module 需要 HTTP 环境）
2. 点击 `📁` 文件夹展开/收起子目录
3. 点击 `📄` 文件链接，在新窗口查看

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript (ES Module)
- ES6 Class 模块化封装
- 递归渲染引擎

## 📦 项目结构

```txt
Learning-Resources/
├── index.html              # 页面骨架
├── style.css               # 全局样式
├── main.js                 # 应用入口
├── README.md               # 项目说明
└── src/
    ├── App.js              # 主应用类（组合器）
    └── core/
        ├── DataManager.js  # 数据管理（树结构 + 路径查找）
        ├── RenderEngine.js # 渲染引擎（DOM 生成）
        ├── FileStorage.js  # 文件存储（Blob URL 管理）
        └── StatsEngine.js  # 统计引擎（文件计数）
```

## 🔧 模块说明

| 模块 | 职责 | 依赖 |
|------|------|------|
| `DataManager` | 树形结构管理（路径查找、文件增删、去重） | 无 |
| `RenderEngine` | 递归渲染 DOM 树，支持 URL 映射 | 无 |
| `FileStorage` | 文件内容存储，Blob URL 生成/撤销 | 无 |
| `StatsEngine` | 递归统计文件数量（纯静态方法） | 无 |
| `App` | 组合以上模块，协调工作流，绑定 UI 事件 | 全部 |

## 🔧 扩展开发

### 数据结构说明

数据存储在 `DataManager.data` 中，规则如下：

- 对象 `{}` → 文件夹
- 数组 `[]` → 文件列表
- `_files` → 当前目录下的文件（当文件夹同时含有子文件夹和文件时使用）
