例1：如图，将质量为 $m=0.1\text{kg}$，长度 $L=2\text{m}$，阻值 $r=2\Omega$ 的均匀金属棒静置在与水平面夹角为 $\theta=37^\circ$，间距为 $d=1\text{m}$ 倾斜平行金属导轨，金属导轨置于垂直导轨平面且磁感应强度大小为 $B=1\text{T}$ 的匀强磁场中，从金属棒静止释放到恰达到最大速度的过程中，定值电阻 $R$ 的焦耳热为 $Q_R=1\text{J}$ （已知金属棒与金属导轨间的动摩擦因数 $\mu=0.5$，重力加速度 $g=10\text{m/s}^2$，导轨电阻不计且足够长，金属棒运动过程中始终与导轨垂直且接触良好，定值电阻 $R=4\Omega$， $\sin 37^\circ=0.6, \cos 37^\circ=0.8$）。
问：（1）金属棒的最大速度 $v_m$。
（2）从金属棒静止释放到恰达到最大速度 $v_m$ 的过程中，金属棒的位移 $S$ 和所用时间 $t$。
解：（1）当 $F_安 = mg\sin\theta - \mu mg\cos\theta$ 时，金属棒有最大速度。又由 $F_安 = BId$，$I = \frac{E}{R_{总}}$，$R_{总} = R + \frac{r}{2}$，$E = Bdv_m$。解得 $v_m = 1\text{m/s}$。
（2）由能量守恒： $mg\sin\theta \cdot S = \mu mg\cos\theta \cdot S + \frac{1}{2} m v_m^2 + Q_R + Q_棒$，又由 $Q_棒 = \frac{r}{R} Q_R$，解得 $S = 6.5\text{m}$。
又由动量定理： $(mg\sin\theta - \mu mg\cos\theta) t - \overline{F_安} t = m v_m - 0$。
又由 $\overline{F_安} = B\bar{I}d$， $\bar{I} = \frac{\bar{E}}{R_{总}}$， $R_{总} = R + \frac{r}{2}$， $\bar{E} = Bd\bar{v}$， $S = \bar{v}t$。
解得 $t = 7.0\text{s}$。

例2：如图，电阻不计的光滑金属导轨由间距为 $\frac{L}{2}$ 的直窄轨 AB、CD 与间距为 $L$ 的直宽轨 EF、GH 和连接直轨 BE、DG 构成，整个导轨置于水平面内，$AB//CD//EF//GH$，BE 与 DG 共线且与 AB 垂直，空间中有竖直向上的匀强磁场。宽轨所在区域磁感应强度大小为 $B$，窄轨所在区域磁感应强度为 $2B$。棒长均为 $L$、质量均为 $m$、电阻均为 $R$ 的金属直棒 $a、b$ 始终与导轨垂直且接触良好。初始时刻，$b$ 棒静止在宽轨上，$a$ 棒从窄轨上某位置以平行于 AB 的初速度 $v_0$ 向右运动，$a$ 棒距窄轨右端足够远，宽轨 EF、GH 足够长。
问：(1) $a$ 棒刚开始运动时，$b$ 棒的加速度大小 $a$。 (2) 经历足够长时间后，通过回路的电荷量 $q$ 与 $b$ 棒的焦耳热。

对 $b$ 列动量定理： $B\bar{I}L t = m v_共 - 0$， $q = \bar{I}t$。则 $q = \frac{m v_0}{2BL}$。

例3：如图所示，两水平虚线间存在垂直纸面向里的匀强磁场，磁感应强度大小为 $B$，边长为 $h$ 的正方形导体框从虚线 1 上方无初速度释放，在释放瞬间 ab 边与虚线 1 平行且相距 $h$。已知导体框的质量为 $m$，总电阻为 $r$，重力加速度为 $g$。 cd 边与两虚线重合时速度大小均为 $v = \sqrt{\frac{gh}{2}}$，且 $\frac{B^2h^2v}{r} < mg$，不计空气阻力，导体框在运动过程中不会发生转动。
问：(1) 导体框穿越磁场的过程中，产生的焦耳热 $Q$。
(2) 导体框从 ab 边与虚线 1 重合到 cd 边与虚线 1 重合时所用时间 $t$。

又由穿越磁场过程： $mg(h + H + h) = \frac{1}{2}mv^2 + Q$。则 $Q = \frac{7}{2}mgh$。
(2) 由动量定理： $mgt - B\bar{I}ht = mv - mv_1$。
又由 $\bar{I} = \frac{\bar{E}}{r}$， $\bar{E} = Bh\bar{v}$， $h = \bar{v}t$，则 $t = \frac{B^2h^3}{mgr} + \sqrt{\frac{h}{2g}}$。

问：(1) 最初导体棒 a 距磁场边界 MN 的距离 $S$。
(2) a、b 两导体棒相距最远的距离 $L$。

则 $X_a = 0.2\text{m}$，由几何关系，则 $S + X_a = X_b + L$ 则 $L = 0.36\text{m}$。

例5：如图，两光滑的固定平行导轨，电阻不计，倾角为 $\theta$，间距为 $d$，下端接有阻值为 $R$ 的定值电阻，导轨间存在磁感应强度大小为 $B$，方向垂直导轨平面向上的匀强磁场。一质量为 $m$、长度为 $d$、阻值为 $R$ 的导体棒 ab 在沿导轨向上的恒定拉力作用下，从静止开始沿导轨向上运动，经时间 $t_0$，ab 到 MN 处且速度达到最大值 $v_m$，此时撤去拉力，ab 上滑到最高点后沿导轨下滑到速度大小为 $v_m$ 的 M'N'（图中未画出）处。已知重力加速度大小为 $g$，从撤去拉力到 ab 向下通过 MN 过程中，通过某一横截面的电荷量为 $q$， ab 始终与导轨垂直且接触良好。
求：(1) 拉力大小 $F$。
(2) $0 \sim t_0$ 时间内回路中产生的总焦耳热 $Q$。
(3) 从撤去拉力到 ab 向下通过 MN 所用时间 $t$。
解：(1) 由题意：当 $F = mg\sin\theta + F_安$ 时，ab 有最大速度 $v_m$。又由 $F_安 = BId$， $I = \frac{E}{2R}$， $E = Bdv_m$。则 $F = mg\sin\theta + \frac{B^2d^2v_m}{2R}$。
(2) 由动量定理： $(F - mg\sin\theta)t_0 - \overline{F_安}t_0 = mv_m - 0$。
又由 $\overline{F_安} = B\bar{I}d$， $\bar{I} = \frac{\bar{E}}{2R}$， $\bar{E} = Bd\bar{v}$， $X = \bar{v}t_0$。
则 $X = \frac{B^2d^2v_m t_0 - 2mv_m R}{B^2d^2} = v_m t_0 - \frac{2mRv_m}{B^2d^2}$。
又由动能定理： $(F - mg\sin\theta)X + W_安 = \frac{1}{2}mv_m^2$。
又由 $W_安 = -Q$ 则 $Q = \frac{B^2d^2v_m^2 t_0}{2R} - \frac{3}{2}mv_m^2$。
(3) 对撤去拉力到最高点，所用时间 $t_1$，平均电流 $\bar{I}_1$。
则： $-mg\sin\theta t_1 - B\bar{I}_1 d t_1 = 0 - mv_m$。
又由最高点到 M'N' 所用时间 $t_2$，平均电流 $\bar{I}_2$。
则： $-mg\sin\theta t_2 + B\bar{I}_2 d t_2 = m(-v_m) - 0$。
又由 $\bar{I}_2 t_2 - \bar{I}_1 t_1 = q$， $t = t_1 + t_2$ 则 $t = \frac{2mv_m + Bdq}{mg\sin\theta}$。

变式：若 ab 达到速度 $v_m$ 后不撤去拉力，而是改变拉力，使金属棒以大小为 $g\sin\theta$ 的加速度向上做匀减速直线运动。则向上匀减速运动过程中，拉力对金属棒的冲量大小。
由 $mg\sin\theta + F_安 - F = m(g\sin\theta)$ 则 $F = F_安$ 则拉力 $F$ 与 $F_安$ 始终大小相等，方向相反。则 $I_F = I_安 = \overline{F_安}t$，又由 $\overline{F_安} = B\bar{I}d$， $\bar{I} = \frac{\bar{E}}{2R}$， $E = Bd\bar{v}$， $X = \bar{v}t$，则 $I_F = \frac{B^2d^2X}{2R}$。又由 $0 - v_m^2 = -2g\sin\theta X$ 则 $I_F = \frac{B^2d^2v_m}{4Rg\sin\theta}$。

例题2：有一斜边长为 $L$ 的等腰直角三角形线圈匝数为 $n$，总电阻为 $r$，以速度 $v_0$ 在光滑水平面上运动，右侧有一磁感应强度为 $B_0$，方向垂直纸面向里的匀强磁场。磁场宽度为 $L$，边界长度足够长，要使线圈匀速通过磁场，对线圈施加一水平向右的拉力 $F$。从线圈刚进入磁场开始计时，求拉力 $F$ 关于时间 $t$ 的表达式。
解：当 $t > \frac{2L}{v_0}$ 时， $F = 0$。
当 $0 < t \leqslant \frac{L}{v_0}$ 时，线圈进入磁场。
$d = 2v_0 t$， $E = nB_0 d v_0$， $I = \frac{E}{r}$， $F_安 = nB_0 I d$。
$F = F_安$，则 $F = \frac{4n^2 B_0^2 v_0^3 t^2}{r}$。
当 $\frac{L}{v_0} < t \leqslant \frac{2L}{v_0}$ 时，线圈离开磁场。
$d' = 2v_0 (t - \frac{L}{v_0})$， $E' = nB_0 d' v_0$， $I' = \frac{E'}{r}$， $F_安' = nB_0 I' d'$。
$F = F_安'$，则 $F = \frac{4n^2 B_0^2 v_0^3 (t - \frac{L}{v_0})^2}{r}$。

(2) 若线圈从刚进入磁场区到速度刚好稳定为 $v$ 的过程中，线圈产生的总焦耳热为 $Q$，求这过程所用时间 $t$。

(2) 由能量守恒： $\frac{1}{2}M v_0^2 + Mgh = \frac{1}{2}M v^2 + Q$。

$t = \frac{4\pi^2 k^2 n^2}{Mgr} (\frac{v^2 - 2gh}{2g} + \frac{Q}{Mg}) + \frac{v - \sqrt{2gh}}{g}$。

在 $t = \frac{T}{2}$ 时刻，油滴做类平抛运动 $\frac{L}{2} = v_0 t$ ⑤， $\frac{d}{2} = \frac{1}{2} a t^2$ ⑥。
$ma = mg + q\frac{U}{d}$ ⑦。 则 $\frac{q}{m} = \frac{4(r+R)}{N R B_0 T}$，由楞次定律，油滴带负电。
分析：由于金属板间电压与定值电阻同，由 ①、②、③，则 $U = IR = \frac{E}{r+R}R = \frac{2N B_0 R d^2}{(r+R)T}$。
由 ④、⑦，则 $a = 2g$。由 ⑥、⑤，则 $t = \frac{T}{4}$， $\frac{d}{2} = \frac{1}{2} a t^2 = \frac{1}{2} 2g \cdot (\frac{T}{4})^2 = \frac{1}{16} g T^2$ 则 $d = \frac{1}{8} g T^2$。
由 ④，则 $\frac{q}{m} = \frac{gd}{U} = \frac{gd}{\frac{2N B_0 R d^2}{(r+R)T}} = \frac{g(r+R)T}{2N B_0 R d} = \frac{g(r+R)T}{2N B_0 R \frac{1}{8} g T^2} = \frac{4(r+R)}{N B_0 R T}$。
由楞次定律，在 $t=0$ 到 $t=\frac{T}{2}$ 时刻，金属板上极板电势高，则电场强度方向竖直向下。
由油滴匀速，电场力与重力平衡，油滴带负电。
(2) 在 $t = \frac{7}{8}T$ 到 $t=T$ 之间，油滴做类平抛运动， $\Delta t_1 = T - \frac{7}{8}T = \frac{1}{8}T$。

在 $t=T$ 到 $t = \frac{3}{2}T$ 之间，油滴做匀速直线运动。
$x_2 = v_y \Delta t_2$，则 $\Delta t_2 = \frac{3}{16}T < \frac{T}{2}$， $x_2 = v_0 \Delta t_2$，则 $x_2 = \frac{3}{8}L$。
则 $x = x_1 + x_2 = \frac{1}{4}L + \frac{3}{8}L = \frac{5}{8}L$。

解：(1) 对线圈： $E = N \cdot 4k \cdot \pi R^2 - N \cdot k \cdot \pi [(2R)^2 - R^2] = N k \pi R^2$。
由 $I = \frac{E}{R_总}$， $R_总 = r + \frac{2r}{2} = 2r$， 则 $I = \frac{N k \pi R^2}{2r}$。
由楞次定律，感应电流方向从 a 端指向 b 端。
(2) 当 $B_0 d v_m = E$ 时，速度最大。 又由 $B_0 \bar{I} d t = m v_m - 0$。
$q = \bar{I} t$，则 $q = \frac{m k N \pi R^2}{B_0^2 d^2}$。
红笔笔记：(1) 由 I 区 $E_1 = N \frac{\Delta \Phi_1}{\Delta t} = N \cdot \frac{\Delta B_1}{\Delta t} S_1 = N \cdot 4k \cdot \pi R^2$， II区 $E_2 = N \cdot \frac{\Delta B_2}{\Delta t} S_2 = N \cdot k \cdot \pi [(2R)^2 - R^2]$。又由 $E_总 = E_1 - E_2$ (由楞次定律，这两种电动势对应电流方向相反)。
