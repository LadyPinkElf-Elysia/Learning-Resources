# 概率

已知：甲盒子装有2个黑球和1个白球，乙盒子装有2个白球（所有黑、白球除颜色外完全相同）。现从甲、乙盒子中各自任取一个球交换放入另一个盒子，重复n次这样的操作后 $(n\in \mathrm{N^*})$ ，将甲盒子中黑球个数记为 $X_{n}$ ，甲盒子恰有2个黑球的概率记为 $a_{n}$ ，甲盒子恰有1个黑球的概率为 $b_{n}$ 。  

(1)求$a_1，b_1$值（2分）  

(2)求证： $\{2a_{n} + b_{n} - \frac{6}{5}\}$ 为等比数列（ $n\in \mathrm{N^*}$ ），并求出 $\{a_{n}\}$ ， $\{b_{n}\}$ 通项公式（12分）  

(3)求 $X_{n}$ 的分布列及其期望（其中 $n\in \mathrm{N^*}$ 且 $n\geqslant 2$ ）（3分）  

---
注解

(1)

交换一次后，若甲中恰有2个黑球乙：那么必是甲中的白球与乙中白球交换，由甲中的白球只有1个，概率为$\frac{1}{3}$，乙中全为白球，概率为1，则 $a_{1} = \frac{1}{3}\times 1 = \frac{1}{3}$  

交换一次后，若甲中恰有1个黑球：那么必是甲中黑球与乙中白球交换，由甲中的黑球有2个， 概率为$\frac{2}{3}$ ，乙中全为白球， 概率为$1$，则 $b_{1} = \frac{2}{3}\times 1 = \frac{2}{3}$  

--- 

(2)

根据题意，由全概率公式

交换 $n+1$ 次后
- 若甲中恰有2个黑球$(\mathrm{X}_{n + 1} = 2)$ 有两种可能：

    - 在 $\mathrm{X}_{n} = 1$ 时，甲中白球与乙中黑球换
    $P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 1) = \dfrac{2}{3}\times \dfrac{1}{2} = \dfrac{1}{3}$ 

    - 在 $\mathrm{X_{n}} = 2$ 时，甲中白球与乙中白球换
    $P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 2) = \dfrac{1}{3}\times 1 = \dfrac{1}{3}$ 

    则 $a_{n+1} = P(\mathrm{X}_{n + 1} = 2) = P(\mathrm{X}_{n} = 1)P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 1) + P(\mathrm{X}_{n} = 2)P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 2)$

    即 $a_{n + 1} = \dfrac{1}{3}a_{n} + \dfrac{1}{3}b_{n}$

- 若甲中恰有1个黑球 $(\mathrm{X}_{n+1} = 1)$ 有三种可能：  

    - 在$\mathrm{X}_{n} = 0$ 时，甲中白球与乙中黑球换
    $P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 0) = 1\times 1 = 1$  
    - 在$\mathrm{X}_{n} = 1$ 时，甲中黑球与乙中黑球换，或甲中白球与乙中白球换
    $P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 1) = \dfrac{1}{3} \times \dfrac{1}{2} + \dfrac{2}{3} \times \dfrac{1}{2} = \dfrac{1}{2}$ 
    - 在$\mathrm{X}_{n} = 2$ 时，甲中黑球与乙中白球换， $P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 2) = \dfrac{2}{3} \times 1 = \dfrac{2}{3}$  

    则 $b_{n + 1} = P(\mathrm{X}_{n + 1} = 1) = P(\mathrm{X}_{n} = 0)P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 0) + P(\mathrm{X}_{n} = 1)P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 1) + P(\mathrm{X}_{n} = 2)P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 2)$
    即 $b_{n + 1} = -\dfrac{1}{2}b_{n} - \dfrac{1}{3}a_{n} + 1$

解 $a_{n}, b_{n}$ 方法：  

方法一：  

$a_{n + 1} = \dfrac{1}{3}a_{n} + \dfrac{1}{3}b_{n}①$ 
$b_{n + 1} = -\dfrac{1}{2}b_{n} - \dfrac{1}{3}a_{n} + 1②$ 
由题， $2a_{n + 1} + b_{n + 1} - \dfrac{6}{5} = \dfrac{1}{6}(2a_{n} + b_{n} - \dfrac{6}{5})$ 
得： $2a_{n} + b_{n} = \dfrac{2}{15}(\dfrac{1}{6})^{n - 1} + \dfrac{6}{5}$  

联立解得 $a_{n}, b_{n}$  

方法二： 
$a_{n + 1} = \dfrac{1}{3}a_{n} + \dfrac{1}{3}b_{n}①$ 
$b_{n + 1} = -\dfrac{1}{2}b_{n} - \dfrac{1}{3}a_{n} + 1②$ 
设 $b_{n + 1} + \lambda a_{n + 1} + \mu = p (b_{n} + \lambda a_{n} + \mu)③$ 
将 $①$ 、 $②$ 代入 $③$ 式，则： $\dfrac{2\lambda-3}{6}b_{n} + \dfrac{\lambda-1}{3}a_{n} + \mu +1 = p b_{n} + p\lambda +p\mu$ 则  

则  

$$
\begin{cases}
    \dfrac{2\lambda-3}{6} = p \\
    \dfrac{\lambda-1}{3} = p\lambda \\
    \mu + 1 = p\mu
\end{cases}
$$ 

则  

$$
\begin{cases}
    \lambda = \dfrac{1}{2} \\
    \mu = -\dfrac{3}{4} \\
    p = -\dfrac{1}{3}
\end{cases}
$$

或

$$
\begin{cases}
    \lambda = 2 \\
    \mu = -\dfrac{6}{5} \\
    p = \dfrac{1}{6}
\end{cases}
$$

- - -  

正式解答  

(1) 由题, $b_{1} = \dfrac{2}{3} \times 1 = \dfrac{2}{3}$ , $a_{1} = \dfrac{1}{3} \times 1 = \dfrac{1}{3}$ 。  

(2) 由题, $X_{n} = 0,1,2$ 。则甲盒中恰无黑球概率为 $1 - a_{n} - b_{n}$ 。  

由 $a_{n + 1} = P(\mathrm{X}_{n + 1} = 2) = P(\mathrm{X}_{n} = 1)P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 1) + P(\mathrm{X}_{n} = 2)P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 2)$  

其中 $P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 1) = \dfrac{2}{3} \times \dfrac{1}{2} = \dfrac{1}{3}$ , $P(\mathrm{X}_{n + 1} = 2\mid \mathrm{X}_{n} = 2) = \dfrac{1}{3} \times 1 = \dfrac{1}{3}$ ，且 $P(\mathrm{X}_{n} = 1) = b_{n}$ , $P(\mathrm{X}_{n} = 2) = a_{n}$  

则 $a_{n + 1} = \dfrac{1}{3}a_{n} + \dfrac{1}{3}b_{n}$ 。  

由 $b_{n + 1} = P(\mathrm{X}_{n + 1} = 1)= P(\mathrm{X}_{n} = 0)P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 0) + P(\mathrm{X}_{n} = 1)P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 1) + P(\mathrm{X}_{n} = 2)P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 2)$  

其中 $P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 0) = 1\times 1 = 1$  

$P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 1) = \dfrac{2}{3}\times \dfrac{1}{2} + \dfrac{1}{3}\times \dfrac{1}{2} = \dfrac{1}{2}$  

$P(\mathrm{X}_{n + 1} = 1\mid \mathrm{X}_{n} = 2) = \dfrac{2}{3}\times 1 = \dfrac{2}{3}$  

且 $P(\mathrm{X}_{n} = 0) = 1 - a_{n} - b_{n}$  

则 $b_{n + 1} = - \dfrac{1}{2}b_{n} - \dfrac{1}{3}a_{n} + 1$ 。(8分)  

由 $2a_{n + 1} + b_{n + 1} - \dfrac{6}{5}= 2(\dfrac{1}{3}a_{n} + \dfrac{1}{3}b_{n}) + (-\dfrac{1}{2}b_{n} - \dfrac{1}{3}a_{n} + 1) - \dfrac{6}{5}= \dfrac{1}{6}(2a_{n} + b_{n} - \dfrac{6}{5})$  

又由 $2a_{1} + b_{1} - \dfrac{6}{5} = 2\times \dfrac{1}{3} + \dfrac{2}{3} - \dfrac{6}{5} = \dfrac{2}{15}\neq 0$  

则 $\{2a_{n} + b_{n} - \dfrac{6}{5}\}$ 是首项为 $\dfrac{2}{15}$ ,公比为$\dfrac{1}{6}$的等比数列。(10分)  

则 $2a_{n} + b_{n} - \dfrac{6}{5} = (\dfrac{1}{6})^{n - 1}(2a_{1} + b_{1} - \dfrac{6}{5})$  

所以 $2a_{n} + b_{n} = \dfrac{2}{15}(\dfrac{1}{6})^{n - 1} + \dfrac{6}{5}$  

由 $a_{n + 1} = \dfrac{1}{3}a_{n} + \dfrac{1}{3}b_{n} = \dfrac{1}{3}a_{n} + \dfrac{1}{3}[\dfrac{2}{15}(\dfrac{1}{6})^{n - 1} + \dfrac{6}{5} - 2a_{n}]$ 

则 $a_{n + 1} = -\dfrac{1}{3}a_{n} + \dfrac{1}{45}(\dfrac{1}{6})^{n - 1} + \dfrac{2}{5}$

由于 $a_{1} = \dfrac{1}{3}$ ，则 $a_{n} = \dfrac{1}{15}(\dfrac{1}{6})^{n - 1} + \dfrac{2}{5}$

由 $b_{n} = \dfrac{2}{15}(\dfrac{1}{6})^{n - 1} + \dfrac{6}{5} - 2a_{n}$ ，则 $b_{n} = \dfrac{1}{15}(\dfrac{1}{6})^{n - 1} + \dfrac{2}{5}$

由 $X_{n} = 0,1,2$ ，则 $X_{n}$ 分布列如下：  



由 $E(\mathrm{X}_{n}) = 0\times (1 - a_{n} - b_{n}) + 1\times b_{n} + 2\times a_{n} = 2a_{n} + b_{n}$ 又由(2)， $\mathrm{E}(X_{n}) = 2a_{n} + b_{n} = (2 / 15)(1 / 6)^{n - 1} + 6 / 5$ ( $n\geq 2$ 且 $n\in \mathrm{N}^{*}$ ) (17分)  

评分细则：  

$①$ $a_1、b_1$ 各1分。  

$②$ $a_{n + 1}$ 对应全概率公式1分，条件概率共1分，结论1分； $b_{n + 1}$ 同理。  

$③$ 判断 $\{2a_{n} + b_{n} - 6 / 5\}$ 是等比为1分，验首项不为0和结论共1分。  

$④$ $a_{n},b_{n}$ 通项公式各2分。  

$⑤$ $X_{n}$ 分布列2分。  

$⑥$ $\mathrm{E}(X_{n})$ 结果1分。
